## The game in one paragraph

An isometric, grid-based, turn-based dungeon RPG with pixel-art graphics and retro synthesized audio,
made in **Godot 4.7.2**. The player controls a party of four — **Fighter, Rogue, Cleric, Mage** — using
D&D 5e-style rules (from the freely licensed SRD). Dungeons, treasure, monsters, spells, items and
character progression. The user (Paul) designs and builds the maps in the Godot editor, may import some
graphics and sounds of his own, and playtests. Claude writes the code and generates the art and audio
that the user doesn't supply.

## Licensing notes (important)

  "Dungeons & Dragons" name/logo or non-SRD monsters (e.g. the beholder, mind flayer).

## Art specs (so user-made and generated assets match)
- Characters: **16×24 px** (14×22 drawn + 1px outline), feet at the bottom centre.
- Floor tiles: **32×16 px** diamonds (2:1 isometric).
- Wall blocks: 32 px wide, **40 px** tall faces; lit face = lower-left, darker = lower-right.
- Monsters: e.g. Eye Tyrant 32×32 floating.
- Effects: fireball 16×16 (6 frames), explosion 32×32 (7 frames).
- PNG with transparency; import in Godot with **Filter: Nearest**, no mipmaps.
- Sounds: WAV (44.1 kHz, 16-bit, mono) or OGG.

## Palettes used
- Dungeon floor: (22,20,26) (38,36,44) (54,52,60) (72,69,76) (92,88,94) (114,108,112)
- Dungeon bricks: (26,24,30) (46,43,50) (64,60,66) (84,78,82) (106,98,98) (128,118,114)
- Fire: (110,20,10) (200,50,20) (255,130,30) (255,210,80) (255,250,200)
- Sprite outline: (20,16,24); full hero palette is the `P` dict in `tools/make_iso_party.py`.
- Lighting look: cool dim ambient (≈0.34, 0.36, 0.50) + warm torch light (1.0, 0.68, 0.36).

## What's in this package

`tools/` — Python 3 generator scripts (need **Pillow** and **numpy**; `ffmpeg` only for the videos).
**Note:** the scripts still expect their original flat layout: run them from one folder, where each
writes to subfolders next to itself (`cave/`, `fireball/`, `iso/`, `sfx/`) and reads `eye_tyrant_sheet.png`
and earlier outputs from there (order: eye_tyrant_anims → cave_textures → fireball → sfx → iso_party →
iso_fireball → iso_dice). Adapt their paths when moving them into the project's `tools/`.
They were written for the concept mock-ups: the hero sprites, Eye Tyrant, effects and sounds are
reusable, but the room/scene scripts draw whole scenes and must be broken into real tiles for Godot.

| Script | Makes |
|---|---|
| `make_eye_tyrant.py` | Eye Tyrant 32×32 sprite |
| `make_eye_tyrant_anims.py` | Eye Tyrant sheet: rows = idle(8), blink(6), attack(6), hurt(4), death(9); 32×32 cells |
| `make_cave_textures.py` | 64×64 first-person cave textures (from an earlier first-person idea; not needed for iso) |
| `make_fireball.py` | fireball_sheet (6×16px), explosion_sheet (7×32px) + first-person demo |
| `make_iso_party.py` | Hero sprites (pixel grids in the file), iso floor/wall drawing, the mock-up room & UI |
| `make_iso_fireball.py` | Animated fireball cast in the iso room (uses `render(f, st)` hooks in make_iso_party) |
| `make_iso_dice.py` | d20 save + 8d6 damage dice overlay; also synthesizes dice sounds |
| `make_sfx.py` | All base sound effects |
| `make_iso_fireball_video.py` | Syncs SFX to the animation → MP4 |

`assets/` — the generated outputs:
- `sprites/` eye_tyrant_32.png, eye_tyrant_sheet.png, party_sprites.png (preview, 8× scaled)
- `effects/` fireball_sheet.png, explosion_sheet.png
- `sfx/` torch_ambience (5 s loop), ui_select, charge, cast_whoosh, fireball_flight, explosion,
  monster_hurt, monster_death, turn_chime, clack_big, clack_small, fail_sting, total_sting
- `previews/` the mock-up images/videos shown to the user (reference for the look we're aiming at)

The user **loved the look and sound** of these mock-ups — keep the new work consistent with them.

## Key mock-up details to reproduce in Godot
- Iso room: stone brick back walls, doorway, wall torches with flicker + warm light (PointLight2D),
  spider web in the corner, bones, treasure chest.
- Combat UI: bottom panel with 4 portraits, HP bars, spell-slot pips (Cleric 4, Mage 4), action menu
  (Attack / Spell / Item / Wait), combat log top-right, "X'S TURN" top-left.
- Tactical overlays: blue = move range, pulsing orange = spell area (Fireball 3×3), yellow = active hero.
- Fireball: staff gem charges with spiralling sparks → arcing projectile with ember trail that lights
  the room → main blast + 8 delayed bursts on the 3×3 → floor flash, screen shake, floating damage
  number → scorch mark stays → monster hurt/death animation → smoke wisps.
- Dice: time freezes before impact, room dims with a spotlight on the target, a panel on the left
  shows the d20 save (purple d20, "9 + 2 = 11 vs DC 15", "FAILED!"), then 8d6 (red d6s dropping in,
  running total, "31 FIRE DAMAGE"). Clack sounds per landing. In the game rolls are real random;
  add a setting: full animation / quick / off (full maybe only for crits & bosses).
- Rules shown: Fireball = 8d6 fire, DEX save vs spell DC (DC 15 = 8 + prof 3 + INT 4), full damage on
  a fail, half on success. Eye Tyrant DEX +2.

## Roadmap (agreed rough plan)
- **Phase 0 — Setup:** Godot project for 4.7.2, folder structure (scenes/, scripts/, data/, assets/,
  tools/), `CLAUDE.md` design doc (from this file), git + GitHub repo (recommended for backup), import
  settings for pixel art, iso TileSet (floor, walls, doorway) the user can paint with, placeable marker
  scenes (party start, monster spawn, chest, torch, door, trap), bring in these assets.
- **Phase 1 — Walking around:** iso map, camera, click-to-move with pathfinding (AStarGrid2D),
  y-sorting/depth, torch lighting.
- **Phase 2 — Combat:** exploration → combat switch, initiative, move + action, d20 vs AC, damage,
  HP/death, simple monster AI, combat UI, damage numbers.
- **Phase 3 — Spells & abilities:** data-driven (Resources); targeting (single, 3×3, line, cone, self,
  ally); spell slots, rests. Mage: Fireball, Magic Missile, Shield. Cleric: Cure Wounds, Bless,
  Sacred Flame. Rogue: Sneak Attack, Hide. Fighter: Second Wind, Shove. VFX + SFX hooks.
- **Phase 4 — Items:** chests, loot, gold, inventory, equipment changing stats, potions, scrolls, keys.
- **Phase 5 — Progression:** XP, levels 1–5, SRD class features, character sheet.
- **Phase 6 — Dungeon features:** doors/locks/keys, traps (Rogue detect/disarm), secret walls, levers,
  room descriptions, triggers, level transitions, more monsters.
- **Phase 7 — Story:** quests, NPCs, dialogue, lore notes.
- **Phase 8 — Wrapper:** title screen, save/load, settings, music, mixing, game over/victory.
- **Phase 9 — Polish & release:** balance, bugs, juice, export builds (Windows/Mac/Linux, itch.io).
- **First milestone (after phases 0–3):** one user-built dungeon, 4 heroes, 2–3 monster types,
  Fireball + healing + melee working, playable start to finish.

Biggest art job still ahead: heroes need **4 facing directions** and idle/walk/attack/cast/hurt/death
animations. Floor/wall art must be exported as individual TileSet tiles.

## Story pitch (optional, not chosen)
"The Weaver's Deep": an apprentice's master vanished in the silver mines beneath Harrowmere, which
broke into sealed, web-choked halls. Levels: Collapsed Mine → Webbed Galleries (spiders, cocooned
miners, the first Eye Tyrant) → Sealed Observatory (an ancient wizard's tower built downward). Twist:
the master broke the seal on purpose; the Eye Tyrants were guards keeping something worse locked in.
(Written for a solo wizard; adapt for a party of four.)
